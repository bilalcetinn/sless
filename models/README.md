# Model Dosyalari

Bu klasor yerel PyTorch checkpoint dosyalari icindir.

Beklenen dosyalar:

```text
mossformergan-best_model.pt
fullsubnet+-best_model.pt
frcrn_best_model.pt
gtcrn_best_model.pt
sgmse_plus_best_model.pt
```

Bu `.pt` dosyalari Git'e eklenmez. `frcrn_best_model.pt` ve `fullsubnet+-best_model.pt` GitHub'in normal 100 MB dosya limitini astigi icin model dosyalarini yerel olarak bu klasore koyun.

Model dosyalarini merkezi olarak paylasmak gerekiyorsa Git LFS, GitHub Releases veya harici bir dosya depolama alani kullanin.
